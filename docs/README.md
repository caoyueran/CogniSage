# CogniSage GitHub Pages

This directory is a static project showcase for GitHub Pages.

Before publishing, replace `REPLACE_WITH_GITHUB_REPOSITORY_URL` in `assets/site-config.js` with the repository URL, for example `https://github.com/OWNER/vulnsage`. The judge feedback form will then create a pre-filled GitHub Issue using `.github/ISSUE_TEMPLATE/judge-feedback.yml`.

Enable GitHub Pages with the `GitHub Actions` source after the workflow is pushed.
